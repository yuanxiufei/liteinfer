# 基准测试

> 所有 GPU 指标都必须在固定硬件、模型、精度、输入尺寸和运行配置下测量。
> 先跑出基线，再据此设定性能目标；不要提前承诺 token/s、每张图秒数或吞吐提升比例。

待产出报告：

| 文件 | 对应 WBS | 必记录项 |
|---|---|---|
| `llm-baseline.md` | 0.3 | 模型版本、上下文长度、生成长度、批大小、首 token 延迟、吞吐、峰值显存 |
| `sdxl-baseline.md` | 0.4 | checkpoint、分辨率、步数、精度、VAE、采样器、耗时、峰值显存 |
| `mixed-workload.md` | 3.x | 与单独运行基线对比的延迟变化、显存峰值、失败率 |
| `lora-train-probe.md` | 0.5 / 5.x | loss 曲线、step 时间、吞吐、GPU 峰值、主机 RAM、checkpoint 可恢复性 |
| `diffusion-train-probe.md` | 0.6 / 6.x | 前向反向是否跑通、张量级对照、资源收益与取舍 |
| `swap-comparison.md` | 4.x | 启用前后峰值显存、step 时间、吞吐、I/O 等待、恢复正确性 |

每次性能记录必须附：

1. GPU 型号、驱动版本、软件版本、模型版本、运行配置。
2. 测试命令与日志位置，保证他人可重复。
3. 与本轮基线相比的软阈值判定（吞吐下降 >10%、P95 延迟上升 >15%、峰值显存增加 >5%、缓存命中率下降 >10 个百分点 → 告警并评审）。
